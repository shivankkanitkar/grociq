# GrocIQ landing page

A lightweight, single-page waitlist website built with plain HTML, CSS and JavaScript. No Node.js, npm, database, API keys or backend are required.

## Publish with GitHub and Vercel

1. Create a new GitHub repository named `grociq`.
2. Upload `index.html` (and this optional `README.md`) to the repository.
3. In Vercel, choose **Add New → Project** and import the `grociq` repository.
4. Keep the default project settings and click **Deploy**.

Vercel will serve `index.html` automatically. The waitlist form is a front-end demo and does not store submissions yet.
